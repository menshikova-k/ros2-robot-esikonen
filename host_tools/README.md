# Python-пульты гусеничного робота

Оба пульта автоматически ищут Arduino/CH340, проверяют ответ прошивки, включают watchdog `T 500` и повторяют активную команду каждые 200 мс.

- `robot_hold_controller.py` — рекомендуемый оконный пульт с режимами `MANUAL` и `CRUISE`.
- `robot_controller.py` — прежний консольный пульт с фиксацией выбранного движения до пробела.

Требуется Python 3.10 или новее, `pyserial` и `pygame`.

## Установка

Windows:

```powershell
cd C:\Users\...\host_tools
py -m pip install -r requirements.txt
```

Orange Pi / Linux:

```bash
cd ../host_tools
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
```

На Linux пользователь должен иметь доступ к последовательному устройству. Если `/dev/ttyUSB0` открывается только через `sudo`, добавьте пользователя в группу `dialout`, затем выйдите из системы и войдите снова:

```bash
sudo usermod -aG dialout "$USER"
```

## Запуск рекомендуемого пульта

Сначала вывесите гусеницы. Подключите Arduino по USB и запустите:

```powershell
py robot_hold_controller.py
```

На Linux:

```bash
python3 robot_hold_controller.py
```

Скрипт сначала проверяет устройства CH340, затем остальные последовательные порты. Если автоматический поиск не сработал, порт можно указать явно:

```powershell
py robot_hold_controller.py --port COM5
```

```bash
python3 robot_hold_controller.py --port /dev/ttyUSB0
```

## Управление

| Клавиша | Действие |
| --- | --- |
| `W` или `↑` | Вперёд |
| `S` или `↓` | Назад |
| `A` или `←` | Поворот дугой влево: внутренняя гусеница 50% |
| `D` или `→` | Поворот дугой вправо: внутренняя гусеница 50% |
| `Q` | Разворот на месте влево |
| `E` | Разворот на месте вправо |
| `Tab` | Переключить `MANUAL` / `CRUISE`; робот сначала останавливается |
| `Пробел` | Аварийная остановка |
| `Esc` | Остановка и выход |
| `+` / `-` | Изменение PWM на 10 |
| `I` | Показать статус |
| `C` | Показать энкодеры |
| `R` | Обнулить энкодеры |

В режиме `MANUAL` движение существует только пока клавиша удерживается. В режиме `CRUISE` однократное нажатие фиксирует движение: `W`/`S` задают прямой ход, а последующее `A`/`D` переводит его в дугу в выбранном направлении. `Q`/`E` фиксируют разворот на месте. `Пробел` снимает фиксацию и немедленно останавливает робот.

Пульт плавно увеличивает PWM при начале движения и плавно снижает его до нуля после обычного отпускания в `MANUAL`. Внешняя гусеница при повороте получает полный PWM, внутренняя — 50%. Переключите раскладку клавиатуры на английскую.

Переключение режима клавишей `Tab` всегда сначала отправляет `S`. Потеря фокуса также сбрасывает зафиксированное движение `CRUISE`.

Окно pygame должно оставаться активным. `Пробел`, потеря фокуса, закрытие окна и аварийная ситуация обходят плавную рампу и немедленно отправляют `S`.

## Безопасность

- При запуске пульт сначала отправляет `S`, затем `T 500`.
- Активная команда повторяется каждые 200 мс.
- При отпускании клавиш пульт плавно уменьшает PWM и затем отправляет `S`.
- При `Пробеле`, потере фокуса, штатном выходе, `Ctrl+C` или большинстве ошибок пульт немедленно отправляет `S`.
- Если программа зависнет, Arduino самостоятельно остановится через 500 мс.
- Аппаратный `FT=LOW` продолжает иметь приоритет над командами пульта.
- Первый запуск выполнять только с вывешенными гусеницами.

Значения можно изменить аргументами:

```powershell
py robot_hold_controller.py --pwm 120 --turn-ratio 0.5 --accel 300 --decel 450 --watchdog 500 --heartbeat 0.2
```

`--accel` и `--decel` задаются в единицах PWM в секунду. При стандартных значениях разгон до PWM 150 занимает около 0,5 с, остановка — около 0,33 с. Не устанавливайте heartbeat длиннее watchdog.

## Если Arduino не находится

1. Закройте Arduino Serial Monitor: один порт нельзя одновременно открыть двумя программами.
2. Выполните `py robot_controller.py --list` старым консольным инструментом.
3. Укажите найденный порт новому пульту через `--port`.
4. Убедитесь, что в Arduino загружена текущая `robot_firmware.ino` и используется скорость 115200.
5. Если `ROBOT READY` повторяется во время движения, проверьте питание и USB-кабель.

## Прежний консольный режим

Если оконная среда недоступна, можно запустить:

```bash
python3 robot_controller.py
```

В этом режиме терминал не видит отпускание клавиши, поэтому направление фиксируется до пробела. Для управления «как радиомашиной» используйте `robot_hold_controller.py`.
