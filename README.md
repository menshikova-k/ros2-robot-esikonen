# ros2-robot-esikonen

**Первенец (Esikoinen - Finn., Firstborn - Eng.) - проект мобильного робота на гусеничной платформе с двумя моторами. **

Самостоятельный проект возник в рамках обучения в открытой лаборатории “ОЛИМП” (ГЭУ, ИТМО), позже адаптирован под курс “ROS2 - введение в робототехнику” (https://stepik.org/course/221157/promo) для отработки навыков разработки мобильной робототехники.

Задачи робота:

**Ориентация и позиционирование**:
- Одометрия. Расчёт перемещения, скорости и направления робота по данным энкодеров колёс.
- Оценка ориентации. Использование IMU для определения поворотов, ускорения и положения корпуса.
- Объединение данных. Совместная обработка одометрии, IMU, камеры и лидара на Orange Pi средствами ROS.
- Обнаружение препятствий. Контроль окружающего пространства с помощью лидара, камеры и ультразвукового датчика.

**Планирование и управление движением**:
- Ручной режим. Управление движением вперёд, назад, влево и вправо, разворотом и остановкой.
- Полуавтоматический режим. Пользователь задаёт целевую точку, а робот самостоятельно выбирает маршрут, траекторию и скорость.
- Автономный режим. Робот самостоятельно определяет цели, планирует движение и корректирует маршрут при появлении препятствий.
- Контроль движения. Arduino управляет моторами и стабилизирует скорость колёс с помощью PID, получая команды от Orange Pi через ROS-мост.

**SLAM и автономное исследование**:
- Построение карты. Робот создаёт и обновляет карту окружающего пространства по данным лидара, камеры и датчиков движения.
- Локализация. Система определяет текущее положение робота на построенной карте.
- Навигация. Карта используется для прокладывания маршрутов и безопасного перемещения между заданными точками.
- Режим исследователя. Робот самостоятельно выбирает неизученные области и получает награду за увеличение исследованной территории.


**Стек для робота**: C++, Python, ROS2, Linux
